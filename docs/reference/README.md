# Reference

Copies of the source documents the tool and the skills follow. Read them; do not edit them.

| File | What |
| --- | --- |
| `drama3.md` | Fish Audio Drama 3 on sglang-omni: install, API, limits, memory, int4/FP8 checkpoints. |
| `voice-direction.md` | Voice direction rules: mood, event and span tags, and their limits. |

The product goal they serve:

> Take a book. Decide how to tell the story best: a narrated audiobook, a full-cast drama, or a conversation-style retelling.
> Output MP3. Always add a subtitle file and the Markdown script you performed.
> Over 1 hour: split into parts of 1 hour, cut at chapters; 2 hours is the loose limit.
> Use Fish Audio Drama 3 for the voices.
