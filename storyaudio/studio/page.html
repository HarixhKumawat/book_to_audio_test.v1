Casting Studio

How to use this window

  1. Cast: for each voice, upload or record a clip of 5–30 s, and type exactly what the clip says. No clip? Write a voice description and press Generate.
  2. Play the clip, then test any line with Preview. When it is right, press Approve.
  3. Script: read and edit who says what. Press Check before you finish.
  4. Press Finish. The agent continues with your choices.
